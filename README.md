# 주변 사물 읽기

휴대폰 카메라로 이미지를 촬영하면 브라우저에서 Teachable Machine 이미지 모델로 분류하고, 결과를 한국어로 안내합니다.

## 실행

카메라 권한과 모델 파일 로드를 위해 페이지를 `localhost` 또는 HTTPS 환경에서 여세요. 프로젝트 폴더에서 아래 명령으로 로컬 서버를 실행할 수 있습니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속한 뒤 카메라 권한을 허용하세요. 휴대폰에서 접속할 때는 `localhost` 대신 HTTPS로 제공되는 주소를 사용해야 합니다. 모바일에서는 후면 카메라를 우선 요청합니다.

## 인식 범위와 개인정보

현재 `my_model/` 모델은 손가락 하트, 버즈, 휴대폰 세 종류만 학습했습니다. 모델이 학습하지 않은 사물까지 식별하는 범용 이미지 인식 기능은 아니며, 확신도가 낮은 결과는 불확실하다고 표시합니다. 판독 이미지와 시간은 브라우저의 `localStorage`에 최대 12건 저장되고 외부 서버로 전송되지 않습니다. 브라우저 저장공간을 지우면 기록도 삭제됩니다.

더 다양한 사물을 인식하려면 모델을 추가로 학습하거나 외부 이미지 인식 서비스를 연결해야 합니다. 외부 서비스를 사용할 경우 브라우저에서 서비스 API를 직접 호출하지 말고, 서버의 API 경유 엔드포인트를 만들어 키를 서버 환경 변수에 보관하세요. 브라우저는 촬영 이미지를 해당 엔드포인트로 전송하고, 서버가 외부 서비스에 요청한 뒤 한국어 결과만 반환하도록 구성하면 됩니다.
